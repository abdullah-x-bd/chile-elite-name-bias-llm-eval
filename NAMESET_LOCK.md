# Nameset lock

## Version

v0.1 pilot and sprint main run

## Status

Locked for pilot and first main run.

This means the project will not change the main surname groups before the pilot unless a source problem is found.

## Design rule

The main run changes surnames only.

First names are kept neutral and reused across both groups.

The comparison is elite coded surname versus common baseline surname.

The comparison is not elite surname versus poor surname.

## Locked source logic

Elite coded surnames come from the source trail around surname affinity and socioeconomic clustering in Santiago.

Common baseline surnames come from high frequency Chilean surname lists.

## What remains open

- A later sensitivity analysis may use the expanded elite family surname set.
- A later paper version should try to replace the common baseline source with direct official Chile Civil Registry material.
- A later robustness check may test Spanish prompts and alternate neutral first names.
