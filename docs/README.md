# The Weight of a Name

Static Phase II research microsite. Serve this directory with any static web server or the existing GitHub Pages docs configuration.

Run `python docs/build_evidence.py` from the repository root to regenerate `docs/data.json`. The script uses only the Python standard library and the repository's frozen core module. It verifies compressed and decoded archive hashes, validates all 8,256 accepted responses against the frozen manifest, and checks primary published point estimates against decoded outputs.

The UI includes all 192 matched decision profiles, all 30 surnames and eight models, recorded forced and abstention-permitted associations, published effect intervals, practical-equivalence results, association-decision coupling, and descriptive secondary comparisons. All animation replays archived evidence; there are no live model calls or fabricated internal model states.

Validation: JavaScript syntax, local references, anchor and element IDs, all archived response schemas, manifest fingerprint, file hashes, and primary effect estimates. Browser visual QA was not performed.
